# Clases

Cinco clases de 120 minutos. Cada carpeta tiene la pregunta de la clase, lo que vas a poder hacer al
terminarla, la agenda, la entrega y las lecturas. Las diapositivas se agregan a la carpeta después de
cada clase.

| | Clase | Producto acumulativo |
|---|---|---|
| 01 | [De un prompt a un agente auditable](01-agente-y-contrato/) | Contrato de tarea y arquitectura |
| 02 | [Herramientas, datos y límites del agente](02-herramientas-y-datos/) | Herramientas con controles y trazas |
| 03 | [Confiabilidad entre corridas](03-confiabilidad/) | Corridas repetidas y sensibilidad |
| 04 | [Supervisión humana y afirmaciones causales](04-supervision-y-causalidad/) | Protocolo de revisión y abstención |
| 05 | [Evaluar y defender un agente confiable](05-evaluacion-y-defensa/) | Informe y defensa final |

Las lecturas son preparación opcional fuera de clase: las ideas necesarias se enseñan en clase.
